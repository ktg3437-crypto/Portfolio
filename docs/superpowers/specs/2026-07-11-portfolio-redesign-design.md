# 포트폴리오 디자인 리뉴얼 설계 (2026-07-11)

## 목표

`modified/` 포트폴리오를 흑백 모노크롬 테마(shadcn 스타일 토큰, Geist 폰트)로 재디자인한다.
주 독자는 **채용담당자(취업용)**. 정량 성과가 없는 신입이므로 "작업물 = 기획력·분석력의 증거"가
첫 화면에서 읽히는 구성을 만든다.

## 범위

`modified/` 디렉토리만 변경. 대상 파일:

| 파일 | 변경 |
|---|---|
| `css/style.css` | 새 테마 토큰으로 전면 재작성 (라이트 `:root` + 다크 `.dark`) |
| `index.html` | 섹션 재배치, About을 히어로에 흡수, 다크모드 토글 버튼, 폰트 링크 교체 |
| `js/main.js` | 다크모드 토글 로직 추가 (기존 works 렌더링·모달·필터 유지) |
| `data/works.json` | 농심 카프리썬 공모전 기획서 항목 추가 (맨 앞) |
| `assets/images/nongshim-*/` | 기획서 PDF 6페이지 → PNG 변환본 + 썸네일 |

루트 `index.html`(구버전)은 건드리지 않는다. 콘텐츠 텍스트(경력·활동·연락처)는 유지한다.

## 레이아웃: 에디토리얼 원컬럼 (A안, 승인됨)

섹션 순서 재배치:

```
히어로(About 흡수) → 01 Work → 02 How I Work → 03 Career
→ 04 Activities & Skills → 05 Contact
```

- **히어로**: 초대형 타이포 헤드라인 + 프로필 사진(`assets/images/profile.jpg` 유지) +
  수상 배지 + 포지셔닝 문단 2~3줄. 기존 About 섹션의 강점 3개(전략적 기획력 / 기획-디자인
  풀사이클 / F&B 전문성)는 기존 hero-stats와 중복이므로 히어로 하단 3열 스트립으로 통합.
- **수상 배지**: "우수사례 공모전 청년영상부문 장려상" 1건 (확정된 정확한 명칭).
  기존 히어로의 "대한상공회의소장상" 표기는 같은 상의 다른 이름이므로 이 명칭으로 교체.
- **번호 매긴 섹션 라벨**: `01 — Work` 형식, Geist Mono.
- **네비**: 얇은 고정 상단바(소개·작업물·경력·연락처) + 우측 끝 다크모드 토글(◐).
- **Work**: 기존 works.json 렌더링·필터·모달 구조 유지. 카드에 "문제 → 기획 → 결과물"
  3줄 요약이 보이도록 카드 템플릿 보강. 농심 항목이 첫 번째.
- **Career**: 세로 타임라인 유지, 연도는 Geist Mono. 시간 역순 정렬(현재 YC가 필라테스보다
  위에 있는 순서 오류 수정).
- **Activities / Skills**: 기존 콘텐츠 유지, 새 테마의 태그·카드 스타일로.
- **Contact**: 다크 배경 대신 보더로 구분된 마무리 섹션 (모노크롬 테마 일관성).

## 디자인 언어

- **토큰**: 사용자 제공 CSS 변수 그대로 `:root`/`.dark`에 적용. Tailwind가 아니므로
  `@theme inline` 블록은 생략하고 변수만 사용.
- **폰트**: Geist + Geist Mono(숫자·라벨·기간), 한글은 **Pretendard** 폴백
  (CDN: cdn.jsdelivr.net pretendard). 기존 Noto Sans KR 제거.
- **스타일**: 순흑/순백 대비, `--radius: 0.5rem`, 1px 보더 중심 카드(그림자는 토큰의
  최소 그림자만), 컬러 악센트 없음 — 위계는 크기·굵기·여백으로만.
- **토큰 예외**: 모달 백드롭과 비디오 레터박스 배경은 테마와 무관하게 항상 검정
  (하드코딩 허용 — 영상 콘텐츠 특성상 양 테마 동일).

## 다크모드

- `<html>`에 `.dark` 클래스 토글.
- 초기값: localStorage 저장값 > `prefers-color-scheme`. 토글 시 localStorage 저장.
- FOUC 방지: `<head>` 인라인 스크립트로 클래스 선적용.
